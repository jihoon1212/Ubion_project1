# Notion을 활용한 업무진행
https://www.notion.so/1ced7edca62a80629584fd5cd8df158d?v=1ced7edca62a80408b04000c0160c10d&source=copy_link

금융 거래 데이터의 심각한 클래스 불균형을 CTGAN 기반 합성 데이터와
머신러닝 분류 모델로 개선한 이상거래 탐지 프로젝트입니다.

## 프로젝트 개요

- 주제: 생성형 AI를 활용한 이상금융거래 탐지
- 데이터: DACON 금융보안원 이상금융거래 데이터
- 문제 유형: 다중분류 및 불균형 데이터 분류
- 주요 모델: XGBoost, LightGBM, 스태킹 모델
- 합성 데이터: CTGAN
- 주요 평가지표: Macro F1-score
- 프로젝트 형태: 팀 프로젝트

## 문제 정의

정상 거래 데이터에 비해 사기 유형별 데이터가 매우 적어
일반적인 분류 모델만으로는 소수 사기 유형을 제대로 탐지하기 어렵습니다.

본 프로젝트에서는 다음 문제를 해결하고자 했습니다.

1. 클래스별 극심한 데이터 불균형
2. 범주형·수치형·시간형 변수가 혼재한 복잡한 데이터
3. 전체 정확도보다 소수 사기 유형의 탐지 성능이 중요한 평가 구조
4. 합성 데이터가 실제 분류 성능에 미치는 영향 검증

## 분석 과정

1. 데이터 구조 및 클래스 불균형 확인
2. 결측치·범주형·시간형 변수 전처리
3. 베이스라인 모델 구축
4. CTGAN을 이용한 사기 유형별 합성 데이터 생성
5. 도메인 기반 파생변수 생성
6. LightGBM 및 XGBoost 모델 최적화
7. 모델 스태킹과 성능 비교
8. Macro F1-score 기준 최종 모델 선정

## 주요 실험

| 단계 | 주요 내용 | 검증 목적 |
|---|---|---|
| Baseline | 기본 전처리와 분류 모델 | 기준 성능 확보 |
| CTGAN | 소수 클래스 합성 데이터 생성 | 클래스 불균형 완화 |
| Feature Engineering | 거래·계좌·시간 관련 파생변수 | 사기 유형 분리력 향상 |
| LightGBM Tuning | 하이퍼파라미터 최적화 | 일반화 성능 개선 |
| Stacking | 복수 모델 결합 | 개별 모델 한계 보완 |

## 핵심 결과

- 최종 Macro F1-score: `정확한 수치 입력`
- 베이스라인 대비 개선 폭: `정확한 수치 입력`
- 가장 효과가 컸던 개선 방법: `직접 확인 후 입력`
- 주요 사기 탐지 변수: `SHAP 분석 결과 입력`

※ 노트북 파일명에 기록된 점수와 실제 최종 제출 점수가 다를 수 있으므로
공식적으로 확인된 수치만 기재했습니다.

## 담당 역할

- 승인매출정보 및 청구입금정보 EDA
- 금융거래 데이터 전처리
- 클래스별 사기 거래 특성 분석
- 도메인 기반 파생변수 설계
- 모델 성능 비교 및 시각화

※ 실제로 수행한 업무만 남기고 팀원이 담당한 부분은 제외합니다.

## 한계 및 개선 방향

- 합성 데이터가 원본 데이터의 통계적 특성을 충분히 보존하는지 추가 검증 필요
- Random Split이 아닌 시간 기준 검증 방식 검토 필요
- 사기 유형별 Recall과 오탐률 분석 필요
- 실제 운영 환경에서는 데이터 드리프트 모니터링 필요
